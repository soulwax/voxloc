# voxloc

Pure Dart game localization library featuring CLDR-style pluralization (`zero`/`one`/`two`/`few`/`many`/`other`), fallback locale chains (`pt-BR -> pt -> en`), parameter formatting (`{player}`, `{dmg:0.1}`), nested JSON & RFC-4180 CSV importers, and font-glyph prewarm sets.
